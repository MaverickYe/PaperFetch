# 文献快下使用说明

## 1. 导入文献

支持 `.xlsx`、`.csv`、`.tsv` 和每行一个 DOI 的 `.txt`。Excel 中如果存在 DOI、标题、中文标题、英文标题或 URL 列，程序会自动识别。

也可以直接在页面输入一个或多个 DOI。

## 2. 选择论文

上传后论文立即出现在“待处理”列表。可以：

- 勾选单篇或多篇；
- 勾选全部；
- 输入起始序号和结束序号；
- 点击“一键获取标题”。

标题查询和下载相互独立，可以边获取标题边调整选择。

## 3. 下载流程

自动下载只处理当前勾选项目。成功获得有效 PDF 的论文会自动进入“已完成”。未成功的论文继续留在“待处理”，并显示 DOI、出版社、开放获取和检索入口等备用链接。

需要机构权限的论文，请在浏览器中完成学校登录或其他授权，再通过链接下载。下载完成后回到软件点击“标记已完成”。程序不会读取或校验外部浏览器中的文件；首次标记时会提醒一次，之后不重复提醒。

## 4. 暂停与恢复

“暂停”只停止当前下载调度，不删除已经完成的文件。重新打开软件后，批次、选择状态、标题、下载状态和手动完成记录会从本地数据库恢复。

## 5. 保存位置

在设置中为新批次选择保存文件夹。修改保存位置不会迁移已经存在的批次。

## 6. 清理列表

清除旧批次前请确认不再需要其中的记录或 PDF。清理列表只作用于软件批次，不会修改原始 Excel，也不会修改项目中的科研工作簿。
